# Image Gen artwork for Power BI

Three original AI-generated decorative PNGs, created with OpenAI Image Gen for this GA4 report. The violet, lavender and white palette matches the existing theme. All three files have transparent alpha channels; no metric data or report text is baked into them.

| File | Use |
|---|---|
| ecommerce-cover.png | Welcome page hero; 1536 × 1024, use at about 450 × 300 |
| acquisition-storefront.png | Acquisition opener or tooltip; square |
| shopping-journey.png | Funnel & products opener or tooltip; square |

Open gallery.html for a preview and individual PNG downloads. See manifest.json for exact dimensions.

## Insert into Power BI

1. Insert → Image, choose the original PNG.
2. Preserve aspect ratio and use Fit rather than stretching or cropping.
3. Position outside the chart plotting area. For a 1600 × 900 welcome canvas, the cover art fits around x=1080, y=220, width=450, height=300.
4. Keep headlines, KPI values, slicers and navigation as native editable report elements. These assets carry no measured values and are not a source of data.
5. In the Selection pane, name the image and mark it decorative where supported; otherwise provide concise descriptive alt text.

These are unbranded illustrations, not photographs or depictions of actual Google Merchandise Store SKUs. Do not use them as product thumbnails for real item-level records.

## Generation brief

Premium matte 3D clay illustration, soft studio lighting, violet #6550D9, deep violet #423293, pale lavender and white, transparent background. No words, numbers, logos or fake chart data. Cover: shopping bag, folded tee, mug, blank receipt and cursor. Acquisition: small storefront and converging discovery paths. Journey: shopping cart with merchandise, bag and confirmation tile. Original PNGs are preserved without post-generation editing.
